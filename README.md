# LifeQuest Web MVP

Модульный прототип на HTML, CSS и JavaScript ES Modules.

## Страницы

- `index.html` — публичная главная страница.
- `register.html` — отдельная страница входа, регистрации и демо-восстановления пароля.
- `workspace.html` — рабочее пространство после входа.

## Запуск

ES-модули не следует запускать через `file://`. Запусти локальный HTTP-сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000

Также можно открыть папку в VS Code и запустить через расширение Live Server.

## Демо-возможности

- Главная страница с обзорными карточками.
- Планировщик на сегодня, неделю и месяц с быстрым добавлением и отметкой выполнения задач.
- Сферы жизни, цели, связанные задачи и проекты со статусами «Запланирован», «В работе» и «Завершён».
- Быстрое добавление задач из раздела задач; проекты до активации не учитываются как активные.
- Привычки с расписанием повторения, датами начала/окончания и ежедневными отметками; цели отказа, объекты заботы, спортивные активности, семейные дела и хобби с необязательным регулярным расписанием.
- Игровой профиль: 30 уровней, XP, достижения и магазин наград с описанием, стоимостью в RP, минимальным уровнем, типом и выбором повторной покупки.
- Отдельные публичная главная страница и страница аккаунта.
- Светлая, тёмная и серая темы с переключателем и сохранением выбора в браузере; выбор одинаково действует для участника и администратора.
- Регистрация и вход в локальном демо-режиме.
- Кнопка выхода в профиле и в боковом меню.
- Демо-смена пароля через форму восстановления на странице аккаунта.
- Квесты: добавление и отметка выполнения.
- Финансы: ручное добавление доходов и расходов.
- Семейная страница с ролями.
- Админ-панель со списком аккаунтов и переключением демо-ролей.
- Адаптивная вёрстка для мобильных устройств.

## Важно о безопасности

Это **frontend-only прототип**, а не готовая production-система. Пароли и сессия хранятся в `localStorage`, а роль администратора можно подделать через инструменты браузера. Не используй реальные пароли и персональные данные. Перед публикацией необходимо перенести аутентификацию и авторизацию на сервер (например, Firebase Authentication + Firestore или собственный API), хранить только хеши паролей, проверять права на сервере, настроить валидацию, ограничения запросов, настоящее восстановление пароля по email и политику приватности.

## Структура

```text
index.html
css/styles.css
js/
  app.js                    # точка входа рабочего пространства
  auth-guard.js             # проверка сессии до показа рабочего пространства
  config.js
  landing.js                # публичная главная страница
  register.js               # вход, регистрация и восстановление пароля
  theme.js                  # переключение темы
  app/
    runtime.js              # навигация, состояние и отображение страниц
    workspace.js            # запуск приложения и подписки на события
    events/
      admin-users.js         # фильтры и изменение данных пользователей
      click.js               # обработчики действий
      forms.js               # обработчики форм
  core/
    events.js
    storage.js
  services/
    auth.service.js
    family.service.js
    quest.service.js
    finance.service.js
    life.service.js
  ui/
    render.js
  pages/
    home.page.js
    life.page.js             # фасад для разделов «Жизнь»
    life/
      shared.js              # общие данные и форматирование
      planner.page.js        # сегодня, неделя и месяц
      collections.page.js    # сферы, цели, задачи и другие коллекции
      dialogs.page.js        # формы планирования и повторений
      progression.page.js    # персонаж, уровни и достижения
    quests.page.js
    finance.page.js
    family.page.js
    profile.page.js
    admin.page.js
```

JavaScript использует ES-модули на всех страницах. `app.js` запускает рабочее пространство, `app/` разделяет состояние и обработчики пользовательских событий, а `pages/`, `services/`, `core/` и `ui/` отвечают за интерфейс страниц, бизнес-логику, общие механизмы и отображение соответственно. `life.page.js` сохраняет прежний интерфейс для маршрутизации и передаёт рендеринг специализированным модулям `pages/life/`.


## Права администратора
Администратор может управлять ролями пользователей, менять почту и пароль обычных аккаунтов (данные администраторов защищены от такого изменения), добавлять/изменять/удалять квесты и добавлять/изменять/удалять операции в Финансовом хабе. Управление доступно после входа под ролью администратора. Это всё ещё демонстрационный frontend: для реального запуска авторизацию и проверку прав необходимо перенести на сервер.
