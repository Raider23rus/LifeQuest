# LifeQuest Web MVP

Модульный прототип на HTML, CSS и JavaScript ES Modules.

## Страницы

- `index.html` — публичная главная страница.
- `register.html` — отдельная страница входа, регистрации и демо-восстановления пароля.
- `workspace.html` — рабочее пространство после входа.

## Запуск

ES-модули не следует запускать через `file://`. Запусти локальный HTTP-сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000

Также можно открыть папку в VS Code и запустить через расширение Live Server.

## Демо-возможности

- Главная страница с обзорными карточками.
- Отдельные публичная главная страница и страница аккаунта.
- Светлая и тёмная темы с переключателем и сохранением выбора в браузере; выбор одинаково действует для участника и администратора.
- Регистрация и вход в локальном демо-режиме.
- Кнопка выхода в профиле и в боковом меню.
- Демо-смена пароля через форму восстановления на странице аккаунта.
- Квесты: добавление и отметка выполнения.
- Финансы: ручное добавление доходов и расходов.
- Семейная страница с ролями.
- Админ-панель со списком аккаунтов и переключением демо-ролей.
- Адаптивная вёрстка для мобильных устройств.

## Важно о безопасности

Это **frontend-only прототип**, а не готовая production-система. Пароли и сессия хранятся в `localStorage`, а роль администратора можно подделать через инструменты браузера. Не используй реальные пароли и персональные данные. Перед публикацией необходимо перенести аутентификацию и авторизацию на сервер (например, Firebase Authentication + Firestore или собственный API), хранить только хеши паролей, проверять права на сервере, настроить валидацию, ограничения запросов, настоящее восстановление пароля по email и политику приватности.

## Структура

```text
index.html
css/styles.css
js/
  app.js
  config.js
  core/
    events.js
    storage.js
  services/
    auth.service.js
    quest.service.js
    finance.service.js
  ui/
    render.js
  pages/
    home.page.js
    quests.page.js
    finance.page.js
    family.page.js
    admin.page.js
```

Каждая страница и бизнес-функция изолирована в собственном модуле. `app.js` отвечает за маршрутизацию и связывает события между модулями.


## Права администратора
Администратор может управлять ролями пользователей, добавлять/изменять/удалять квесты и добавлять/изменять/удалять операции в Финансовом хабе. Управление квестами и финансами отображается после входа под ролью администратора. Это всё ещё демонстрационный frontend: для реального запуска авторизацию и проверку прав необходимо перенести на сервер.
